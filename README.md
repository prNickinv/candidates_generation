# Candidates Generation Engine

This project develops candidates generation engine as part of the pipeline for providing user with items that match their queries the most.

In the [eda.ipynb](eda.ipynb) notebook you can find exploratory data analysis. 

The [candidate_generation.ipynb](candidates_generation.ipynb) notebook contains the main code of the search engine as well as the necessary code to reproduce the solution and comments regarding the engine design, choice of features, models, evaluation, potential pitfalls, etc.
